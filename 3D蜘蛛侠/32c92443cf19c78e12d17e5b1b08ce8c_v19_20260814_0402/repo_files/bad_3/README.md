# 4 — NEON THREAD V9

第三人称 3D 城市蛛丝摆荡游戏。项目技术栈保持为 React 19 + TypeScript + Vite + Tailwind CSS + Three.js；所有城市、角色、地标、材质/纹理与视觉内容均由代码或项目内内容生成，不依赖远程运行资产、后端或外部服务器。

## 运行

安装依赖后：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

本地直接体验：解压后双击 `index.html` 或 `play.html`，`file://` 入口会进入同步维护的 `standalone.html`。该入口不是旧版演示页，V9 已纳入同一契约检查。

## 操作

- `WASD`：相对当前相机方向移动；空中与摆荡时进行受限方向修正
- `Shift`：地面冲刺；高速落地后尽量保留摆荡获得的真实水平动量
- 鼠标：第三人称自由观察，包含真实上下俯仰/纵向环绕
- `Space`：真实跳跃；短按低跃、长按高跃，带输入缓存与离地容错
- 按住鼠标左键：准星真实命中建筑表面时连接蛛丝
- 松开鼠标左键：解除蛛丝；不额外添加速度，保留解除瞬间真实速度
- `N`：昼 / 夜切换
- `R`：重置位置
- `Esc`：释放鼠标锁定

## 核心物理与操作

- 主模拟固定为 `1/120s` 物理步进。
- 蛛丝只能连接真实建筑射线命中点，并记录实际锚点与当前实际绳长。
- 摆荡由真实锚点、实际绳长、玩家已有速度与重力形成；超过绳长时仅修正位置并移除向外径向速度，不使用固定圆周动画。
- WASD 摆荡控制严格投影到绳索切平面；高速时降低控制权，保留惯性，不变成自由飞行推进器。
- 松开蛛丝只解除约束，不对 `velocity` 施加额外发射冲量。
- 高速落地不会被固定跑速强行重置；地面过速采用缓慢衰减和方向旋转。
- 玩家与地面/建筑使用真实碰撞；高速运动使用基于实际位移的碰撞微步，并迭代求解蛛丝约束与建筑碰撞，降低高速穿墙。
- 相机具有建筑碰撞保护，避免近景穿入楼体。

## V9 反馈与视角

- 蛛丝拉扯反馈来自真实约束冲量与张力：绳线粗细/亮度、脉冲、锚点反馈和轻微镜头冲击由真实受力驱动，不修改角色动量。
- 蛛丝视觉改为程序化分段线；低张力时可有轻微松弛，高张力/接绳冲量时产生受力振动。
- 释放后的速度感由真实保速 + 相机前瞻、跟随距离和 FOV 提升表现，不通过假加速实现。
- 鼠标上下不再只是改变一个未生效变量：`pitch` 同时进入真实相机环绕和实际 look target，可明显观察/瞄准高楼与低处。
- 相机还会根据升降速度、锚点高度、真实接绳冲量与落地压缩做有限动态反馈。

## 美术与建模

- 原创程序化城市，包括退台建筑、结构角柱、屋顶设备、玻璃冠部、霓虹腰线、道路、街灯、远景天际线与原创地标。
- 玩家代理包含分层装甲、头盔、胸腹护甲、肘膝结构、前臂蛛丝发射器、腿甲、背部装置等程序化模型。
- 跑动、跳跃、下坠和摆荡具有基础姿态/动作反馈；Standalone 入口也同步了相应姿态变化。
- 昼夜照明、城市雾、霓虹局部光和程序化窗灯不依赖远程贴图。

## HUD / 可选增强项

V9 将提示词中的可选项全部实现：

- Speed / Altitude / Vertical Speed HUD
- Web load / Rope length / Distance telemetry
- Compass + heading
- Procedural minimap（真实玩家位置与当前锚点）
- Day / Night lighting

## DOM 契约

React/Vite 与 Standalone 两条入口均保留：

- `id="root"`
- 主真实游戏画布 `data-testid="game-canvas"`

## 公开只读状态接口

两条入口均提供以下只读接口，返回当前真实运行对象快照：

- `window.__game.getState()`
- `window.__player.getState()`
- `window.__camera.getState()`
- `window.__web.getState()`
- `window.__world.getState()`

这些接口不提供瞬移、直接设速、改锚点、改绳长或其他绕过正常输入的写控制能力。
